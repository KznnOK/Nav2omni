# 速度・加速度の振り試験（フェーズ4）

条件: 最高速度 1.5/2.0/2.5/3.0 m/s × 加速度 2/3 m/s² × 横方向加速度 1.5/2.5/3.5 m/s²、
各1回、標準開始位置、経路の余裕 0.15 m、その場回転、AMCLビームモデル、遅れ補償あり。
速度ごとに1回起動し、6条件を連続で実行。

- `runs.csv`: 最終結果（24行）。v2.0_a3_l3.5、v3.0_a3_l2.5、v3.0_a3_l3.5 は再実行の結果。
- `runs_first_pass.csv`: 1回目。上の3条件は、試行間の AMCL 再初期化が反映されないまま
  開始した（推定位置が前回の帰着位置のまま）。2件は壁に接触、1件は開始位置がずれていた。
  mission_trial の place() を、真値と /amcl_pose が開始姿勢から 3 cm・2° 以内に入るまで
  再試行するよう修正した後に、別の起動で再実行した。
- `table.md`: 条件ごとの表（壁との最小距離は、往路のエリア1を出た後と復路の真値から計算）。
