# フェーズ5: 誤差の組み合わせ試験

共通: 採用条件（2.0 m/s・3 m/s²・3.5 m/s²）、`friction_limit_enabled=true`、`mu_drive=0.5`、LiDAR補正あり。
各条件で標準の開始位置3回＋ランダムな開始位置2回（乱数の種 11, 12。条件間で同じ開始位置）。
baseline はご指定は3回だったが、ランダム開始の比較用に5回走らせた。

| 条件 | 内容 | 駆動輪 mu2 |
|---|---|---|
| combo_base | 誤差なし | 0.6 |
| combo_real | IMU バイアス 0.1 deg/s ＋ ドリフト 0.01 deg/s/√s、計測輪（直径+1%、取り付け角度 0.5°、位置 3 mm、量子化）、LiDAR（ピッチ 0.5°、ヨー 0.5°、位置 3 mm） | 0.6 |
| combo_severe | 上に加えて、計測輪の取り付け角度 1°、LiDARピッチ 1°・ヨー 1°・位置 5 mm、計測輪の浮き（0.5 Hz、0.02 s） | 0.5 |

誤差の値はすべて仮値。ファイル: `runs.csv`、`stalls.csv`（停止の監視の回数）、`timeseries/`、`table.md`（`p5_combo_table.py` で生成）、`run_combo.sh`。
結果の要点: 15/15 成功、停止の監視は0回、壁への接触は0。

## 原因として考えられる誤差

条件ごとの切り分け（誤差を1つずつ外した試験）はしていないので、以下は単独試験（補正あり）の結果との照合による推定。

- **復路の行き過ぎ**（base 2〜6 mm → real 7〜14 mm → severe 35〜87 mm）が最も大きく悪化した。
  単独試験で行き過ぎが最大だったのは IMU のドリフト（14.1 mm）、次が計測輪の取り付け角度 1°（7.9 mm）と LiDAR取り付け誤差。real の 12〜14 mm はドリフトとほぼ同じ水準。
  severe の大きな行き過ぎは、推定誤差が最大のときと同じ復路（RETURN、1.2〜1.8 m/s で長い直線を走る区間）で出ており、**計測輪の浮き**で推定がずれたことが主因と考える（単独試験でも浮きは推定誤差が最大の 74 mm）。
  severe は駆動輪の `mu2`=0.5 で計画の `mu_drive`=0.5 と一致しているため、base/real（実際 0.6、計画 0.5）より摩擦の余裕が小さいことも寄与している可能性がある（切り分けていない）。
- **推定誤差のピーク**（base 16〜32 mm → real 22〜27 mm → severe 32〜68 mm）: 計測輪の浮きが主因（上と同じ）。ピークは走行中の高速区間（RETURN / GO_SAKURA の 0.7〜1.8 m/s）で出ている。
- **停止誤差**（最大 6.5 → 13 → 20 mm）: IMUバイアスとドリフト、計測輪の角度・直径の累積（単独試験では各 10〜14 mm）。severe では浮きが加わる。いずれも許容 ±50 mm の内側。
- **整定時間・合計時間**: 行き過ぎの戻りで延びる（復路の整定が最大 1.5 s）。
