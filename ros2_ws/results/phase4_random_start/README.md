# ランダム開始の追加試験（フェーズ4）

2条件 × 3回。開始姿勢は start_region.yaml の範囲（±300 mm, ±150 mm, ±10°、エリア1内で
木枠やサイコロに触れないもの）から seed 101/102/103 で選び、両条件で同じ3姿勢を使用。
経路の余裕 0.15 m、その場回転、AMCLビームモデル、遅れ補償、指令の加速度制限修正（88a6b76）後。

- 2.0 m/s・3 m/s²・3.5 m/s²（採用条件）
- 2.0 m/s・2 m/s²・2.5 m/s²（控えめな条件）

`table.md` が条件ごとの表。壁との最小距離は、往路はエリア1を出た後と復路の真値から計算。
