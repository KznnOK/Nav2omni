# 提案: 摩擦係数から進行方向ごとの加速度上限を計算する

実装はまだしていない。判断用の提案。

## 1. 物理（X配置の駆動輪4つ）
- 各駆動輪が出せる力は、転がり方向（Gazebo の mu2）に最大 μ·N_i。軸方向（mu1、フリーローラ）はほぼ0。
- 荷重は4輪均等（N_i = m·g/4）、荷重移動なし、並進だけ（旋回に力を回さない）と仮定。
- 4輪の転がり方向は車体の対角線（±45°、±135°）。対角線の単位ベクトルを e1, e2（直交）とすると、4輪の力の最小ノルム解から、並進加速度 a が出せる条件は

      |a · e1| ≤ μg/2   かつ   |a · e2| ≤ μg/2

  つまり車体座標で「45°回した正方形」が加速度の可能領域。
- 方向 φ（車体座標、面の方向が 0°）の最大加速度:

      a_max(φ) = (μg/2) · (|cos(φ-45°)| + |sin(φ-45°)|)

  - φ = 0°（面の方向）: 0.707 μg
  - φ = 45°（斜め）: 0.5 μg  → 目安（0.7μg / 0.5μg）と一致

| μ | 面の方向 0.707μg | 斜め 0.5μg |
|---|---|---|
| 0.4 | 2.77 m/s² | 1.96 m/s² |
| 0.6 | 4.16 m/s² | 2.94 m/s² |
| 0.8 | 5.54 m/s² | 3.92 m/s² |
| 1.0 | 6.94 m/s² | 4.91 m/s² |

現在の既定値（max_accel 3.0）に必要な μ: 面の方向で 0.43、斜めで 0.61。max_lateral_accel 3.5 なら斜めで 0.71。

## 2. 入れる場所
`trajectory.py` の `_plan_speed` は、すでに各サンプルで車体座標の進行方向
`direction = atan2(ty, tx) - yaws[i]` を計算している（`speed_limit(direction, g)`）。
ここに加速度の上限を足すだけで済む。

1. 経路上の点 i で、接線 t̂ と法線 n̂（曲率 κ）を車体座標に回す。
2. 遠心加速度 a_n = v²κ を使い、速度の上限を

       v ≤ sqrt( A / (κ · max_u |n̂·e_u|) )        A = k·μ·g/2

   で求める（現在の `sqrt(max_lateral_accel / κ)` の置き換え）。
3. 接線方向の加速度（加減速）は

       a_t ≤ min_u ( A - |a_n · n̂·e_u| ) / |t̂·e_u|     （u = 1, 2）

   で求める（現在の `tangential()` の置き換え）。減速側も同じ上限を使う。
4. 現在の `max_accel` / `max_lateral_accel` は上限として残し、`min` で併用する。

## 3. パラメータ
| 名前 | 既定値案 | 意味 |
|---|---|---|
| `mu_drive` | 0.6 | 駆動輪の摩擦係数（実機で測るまで仮値） |
| `friction_safety` (k) | 0.8 | 摩擦の使用率の上限 |
| `yaw_friction_reserve` | 0.15 | 旋回に回す摩擦の割合（A から引く） |
| `friction_limit_enabled` | false | 既定は今の挙動のまま、比較しやすくする |

## 4. 限界と確認が必要な点
- 荷重移動（加減速で前後輪の荷重が変わる）と、モーター・ドライバ側のトルク上限は入れていない。
- 旋回と並進で摩擦を取り合うため、旋回が大きい区間は `yaw_friction_reserve` で見込む。厳密には輪ごとの力を解く必要がある。
- `command_accel_ratio`（1.3）で指令は計画より攻めているので、上限は計画側に入れ、指令側は制限しない。
- シミュレーションの Gazebo(ODE)は、輪ごとに軸方向と転がり方向を独立に制限する（箱形）ので、上の解析と同じ前提。
- 実機の μ は未測定。試験は 0.4 / 0.6 / 0.8 の結果と照らして k を決めるとよい。
